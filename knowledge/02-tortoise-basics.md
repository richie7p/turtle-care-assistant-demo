# 活動空間
陸龜需要足夠的水平活動面積、可躲藏的遮蔽處，以及明確的溫度梯度。圍欄應避免尖角、可吞食異物與容易攀爬逃脫的結構。空間不能只用「能放得下龜」判斷，還要讓牠能探索、轉身、覓食與自行選擇冷熱區。

# 底材與濕度
底材應依物種原生環境調整，避免長期過濕、粉塵過多或容易誤食造成阻塞的材料。幼龜與部分熱帶種通常需要更穩定的微環境濕度，但仍要保持通風並提供較乾區域。
